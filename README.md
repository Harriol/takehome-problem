## 1. 问题概述

给定一个轮廓（简单多边形）与若干矩形物品（冰箱/货架/离地架/制冰机），
在满足“轮廓内、互不重叠、不挡门、冰箱开门边净空、内开门预留 N×N 空间”等约束
的前提下求解“是否可行 + 各物品中心点坐标与旋转角度（0°/90°）”，
空间充足时优先贴墙摆放；并用 Python 输出与题目参考图片同风格的结果图。
